AlgebraicBoolean · Proof

Why the back-transformation works

Read one true row from a polynomial, save that row as a Boolean AND term, and remove it. Repeat until the polynomial is zero.

Starting point The proof Full adder Subtraction shortcut

Start with a reduced polynomial

Fix a list of n Boolean inputs. Each input is either 0 or 1. An AlgebraicBoolean polynomial p gives an output for every combination of input values. We call a row of the truth table true when its output is 1.

To reduce p, expand the products, replace every positive power of a variable by that variable, and collect matching terms. This preserves every Boolean output because, for example, A2 = A at both 0 and 1. After reduction, a term such as −2AB has coefficient −2 and degree 2, since it contains two variables. A constant has degree 0.

The original gate formulas
NOT
1 − p
AND
pq
OR
p + q − pq
XOR
p + q − 2pq

These formulas give the gate’s Boolean output whenever the input signals are 0 or 1. Applying them throughout a combinational network therefore gives a polynomial that also has only 0 and 1 as outputs on Boolean input rows.

The claim

For any reduced polynomial that outputs 0 or 1 on every Boolean input row, the back-transformation returns an equivalent Boolean expression. Each step extracts exactly one true row. The process takes exactly as many steps as there are true rows, at most 2n.

The proof

  1. 1

    The smallest term reveals a true row

    From the current nonzero polynomial, choose a term with a nonzero coefficient and the fewest variables. Set exactly the variables in that term to 1, and set every other input to 0.

    Say the chosen term is kAB. At the row with A and B both 1, the chosen term contributes k. Every other term of the same or higher degree contains a variable outside A and B, so it vanishes. There are no nonzero terms of lower degree, by how we chose the term. The entire polynomial therefore evaluates to k.

    The same reasoning works for any set of variables in the chosen term. Its coefficient equals the polynomial’s value at the corresponding row. Since that coefficient is nonzero and the only possible outputs are 0 and 1, the coefficient is +1 and the row is true.

    Any tie for the fewest variables can be resolved in any order. If the selected term is the constant +1, its row is the one with every input set to 0.

  2. 2

    AND with the inverse removes just that row

    Use every input exactly once in the Boolean AND term. Use the variable itself where the row has a 1, and its negation where the row has a 0. For inputs A, B, C, the row (1, 1, 0) gives A ∧ B ∧ ¬C. Its algebraic form is m = AB(1 − C).

    Save the Boolean term for the final result. To remove its row from the remaining polynomial, AND the remainder with the inverse of that term.

    pnew = reduce(p(1 − m))

    At the selected row, m = 1, so the new output is 0. At every other row, m = 0, so the output stays what it was. Reduction preserves these values. The remainder still has only 0 and 1 as outputs, so we can apply the first step again.

  3. 3

    The procedure reaches zero and returns the original function

    Each pass removes one true row. Once removed, that row stays false. There are finitely many rows, so eventually every remaining output is 0.

    At that point, the reduced polynomial itself must be zero. If it still had a nonzero term, we could pick a smallest one and evaluate at its row as in step 1. The output would equal its nonzero coefficient, contradicting the fact that every output is 0.

    OR together the Boolean terms saved along the way. Each term is true at just its extracted row, so the OR is true at exactly the original true rows. If the initial polynomial is zero, there are no terms to save and the result is FALSE.

Follow the full adder

The full adder’s sum bit is D = A ⊕ B ⊕ C. Its starting polynomial is

p0 = A + B + C − 2AB − 2AC − 2BC + 4ABC.

We can choose A first among the tied degree-one terms. At (1, 0, 0), all the other terms vanish. The four passes are shown below. In a Boolean term, ¬ means NOT and ∧ means AND.

  1. 1

    Select A. Save A ∧ ¬B ∧ ¬C.

    p1 = B + C − AB − AC − 2BC + 3ABC

  2. 2

    Select B. Save ¬A ∧ B ∧ ¬C.

    p2 = C − AC − BC + 2ABC

  3. 3

    Select C. Save ¬A ∧ ¬B ∧ C.

    p3 = ABC

  4. 4

    Select ABC. Save A ∧ B ∧ C.

    p4 = 0

The result is the OR of the four saved terms, written with ∨ for OR.

D = (A ∧ ¬B ∧ ¬C) ∨ (¬A ∧ B ∧ ¬C) ∨ (¬A ∧ ¬B ∧ C) ∨ (A ∧ B ∧ C)

This is true exactly at (1, 0, 0), (0, 1, 0), (0, 0, 1), and (1, 1, 1). Those are the full adder’s four rows with sum bit 1.

Remove the row by subtraction

The proof also gives a shortcut. The selected row is already true in p, so pm and m have the same output everywhere. Both are 1 at that row and 0 elsewhere.

Two reduced polynomials with the same values on Boolean inputs are identical. Their difference is a reduced polynomial with all outputs zero, and step 3 proved that such a polynomial must be zero. Therefore the reduced product pm is m, with m expanded and collected.

reduce(p(1 − m)) = p − m

In the full adder’s first pass, expand m = A(1 − B)(1 − C) to get A − AB − AC + ABC. Subtract those four terms from p0 to get p1 directly.

Every term in the expanded row polynomial contains all the selected variables. Subtraction cancels the selected term and changes only terms of higher degree. So the search for the next term can move forward through a list ordered by degree.

Using the result

Keep the complete input list throughout the procedure, even when some inputs disappear from the remaining polynomial. Each saved AND term specifies a complete row. Use exact arithmetic so that terms cancel exactly. The gate formulas above generate integer coefficients in the original 0/1 system.

The result gives one AND term per true row, joined by OR. In Boolean algebra this is called canonical disjunctive normal form. Further simplification may combine rows and produce a shorter expression.

A separate local check exercised the algorithm on all 65,814 Boolean functions with zero through four inputs. The proof above applies to any finite number of inputs.
