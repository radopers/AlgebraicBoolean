1. Setting and notation

Fix a finite list of inputs x=(x1,…,xn) with index set N={1,…,n} and Boolean cube {0,1}n. Work with polynomials over the reals. The original AlgebraicBoolean gate translations, for inputs with values in {0,1}, are

¬p↦1−pp∧q↦p⁢qp∨q↦p+q−p⁢qp⊕q↦p+q−2⁢p⁢q

Let red denote expansion, replacement of each positive power xik↦xi, and collection of like terms. Reduction preserves values on the Boolean cube. Consequently, a translated combinational network output is represented by a reduced polynomial that takes values in {0,1} throughout the cube.

For S⊆N, write xS for the monomial supported on S. A reduced polynomial is a linear combination of these monomials.

xS=∏i∈Sxi,x∅=1,p⁡(x)=∑S⊆NcS⁢xS,cS∈ℝ.

The degree of xS is |S|. A coefficient of zero denotes an absent monomial. Let vS be the Boolean input row whose 1-coordinates are exactly the indices in S. Its row polynomial is

mS⁡(x)=∏i∈Sxi⁢∏j∈N∖S(1−xj).

The corresponding Boolean term is the AND of the variables indexed by S and the negations of those indexed by N∖S. Empty products equal 1. In particular, the empty support selects the all-zero row.

mS⁡(vT)={1,ifT=S,0,ifT≠S.

2. Theorem and proof

Theorem. Let p be any reduced polynomial with values in {0,1} on the Boolean cube. At each nonzero stage, choose any nonzero term of minimum degree, save the Boolean AND term for its row, and remove that row by multiplying by the complement of its row polynomial and reducing. Every selected coefficient is +1. The procedure terminates after exactly as many iterations as there are true rows, at most 2n, and the OR of the saved terms agrees with p on the entire cube.

2.1 The selected coefficient

Let cS⁢xS be a term of minimum degree among those with nonzero coefficient. At vS, a monomial xT evaluates to 1 precisely when T⊆S. Thus

p⁡(vS)=∑T⊆ScT=cS.

The second equality holds because each proper subset T⊊S has smaller degree, hence cT=0. As p⁡(vS) is a Boolean value and cS≠0, it follows that cS=1. The argument applies to every minimum-degree choice, including ties and the constant monomial.

2.2 Removal of exactly one row

Save the Boolean term represented by mS. Update the remainder by AND with its inverse.

pnew=red⁡(p⁢(1−mS)).

Since reduction preserves all Boolean evaluations, the row values of the new polynomial are

pnew⁡(vT)=p⁡(vT)⁢(1−mS⁡(vT))={0,ifT=S,p⁡(vT),ifT≠S.

Because the selected row had value 1, this update removes exactly one true row. The new polynomial is reduced and Boolean-valued, so the same selection argument applies at each subsequent nonzero stage.

2.3 Detection of the zero polynomial

For any nonzero reduced polynomial q, choose a nonzero term of minimum degree. The evaluation argument of §2.1 uses only the monomial supports to show that q⁡(vS)=cS≠0 at its selected row. Therefore

(q⁡(x)=0,∀x∈{0,1}n)⟹q=0.

In particular, two reduced polynomials with the same Boolean evaluations are identical, because their difference is reduced and has all evaluations zero.

2.4 Termination and equivalence

Write p0 for the initial polynomial, and let r be the number of rows at which it is 1. After k iterations, exactly r−k true rows remain. Every iteration leaves all other rows unchanged, including rows previously removed. After exactly r iterations, §2.3 implies that the remainder is the zero polynomial. Since the cube has 2n rows, r≤2n.

If the selected supports are S1,…,Sr, the recovered Boolean expression is

⋁j=1r(⋀i∈Sjxi∧⋀i∈N∖Sj¬xi).

Each conjunction is true at precisely its selected row. Their disjunction therefore agrees with the initial polynomial on all inputs. The empty disjunction is FALSE and represents the initial zero polynomial. □

3. Subtraction in place of multiplication

At the selected row vS, both p⁢mS and mS evaluate to 1. At every other Boolean row they both evaluate to 0. The uniqueness result in §2.3 therefore gives

red⁡(p⁢mS)=mS,red⁡(p⁢(1−mS))=p−mS.

Here mS is expanded and like terms are collected. Its expansion is

mS=∑U⊆N∖S(−1)|U|⁢xS∪U.

The summand for U=∅ is xS. Every other summand has degree strictly greater than |S|. Subtraction cancels the selected monomial and changes only coefficients of higher degree. With a fixed order within each degree, the selection can advance through the monomial order as higher-degree coefficients are updated.

4. Full-adder example

The sum output D=A⊕B⊕C has the initial polynomial

p0=A+B+C−2⁢A⁢B−2⁢A⁢C−2⁢B⁢C+4⁢A⁢B⁢C.

Choose A first among the degree-one terms. At iteration j, write mj for the expanded row polynomial and pj for the remainder after removing it.

  1. Select A and save A∧¬B∧¬C.

    m1=A−A⁢B−A⁢C+A⁢B⁢C,p1=p0−m1=B+C−A⁢B−A⁢C−2⁢B⁢C+3⁢A⁢B⁢C.

  2. Select B and save ¬A∧B∧¬C.

    m2=B−A⁢B−B⁢C+A⁢B⁢C,p2=p1−m2=C−A⁢C−B⁢C+2⁢A⁢B⁢C.

  3. Select C and save ¬A∧¬B∧C.

    m3=C−A⁢C−B⁢C+A⁢B⁢C,p3=p2−m3=A⁢B⁢C.

  4. Select A⁢B⁢C and save A∧B∧C.

    m4=A⁢B⁢C,p4=p3−m4=0.

The four saved terms yield the original sum bit.

D=(A∧¬B∧¬C)∨(¬A∧B∧¬C)∨(¬A∧¬B∧C)∨(A∧B∧C).

5. Scope and implementation

  • Keep the full input index set fixed, including inputs absent from the remainder. Each saved term specifies a complete input row.
  • A constant coefficient of +1 selects the all-zero row. The corresponding row polynomial is ∏i∈N(1−xi).
  • The hypothesis concerns values on {0,1}n. For example, 2⁢A takes the value 2 at A=1 and lies outside the theorem.
  • Coefficient arithmetic and zero tests must be exact. Integer arithmetic suffices for polynomials generated by the listed gate translations.
  • A combinational network provides a Boolean function to which the theorem applies. A network with feedback or state requires a specified input/output function before applying the theorem.
  • The output is canonical disjunctive normal form, with one complete term per true row. A smaller gate expression may exist. The row count and coefficient storage can grow exponentially with n.

The local verification in verify_back_transformation.py checked all 65,814 Boolean functions with zero through four inputs and 525,349 extraction steps using exact arithmetic. It checks the chosen coefficient, the reduced product, the subtraction identity, and the remaining truth-table rows.
